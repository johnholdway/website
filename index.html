    Clinical Note Tool

    I am working on a tool for mental health clinicians to help them write notes. It is a work in progress and I will be adding more features to it over time. The initial idea is create a tool that is controled by the clinician and a way to help the process of creating clinical notes without the use of AI. The tool will be a web based application that will be able to be used on any device with a web browser.
